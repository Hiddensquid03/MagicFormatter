This program was created to quickly format text from the reddit bot Card Getter removing all the stuff from it then the card name e.g [SF] [G] these direct you to wiki pages to view the card however arent valid format for deck building websites like archidekt 

HOW DOES IT WORK

this program scans your clip board upon starting the program and removes anything after the dash 
for example
bastion of remembrance - (G) (SF) (txt) (ER)
leaving it as
bastion of remembrance
Which you can then take and import in archidekt without any issues 
It can also handle a longer list of cards over multiple lines
